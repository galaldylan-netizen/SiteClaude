# Cafecito — redesign Hallmark

Fichiers modifiés du thème Shopify Cafecito (copie du thème « Grains dessinés »), redesign complet de la page d'accueil avec le skill Hallmark.
Ils sont installés dans le thème non publié **Cafecito — Hallmark** de la boutique. Le reste du thème est inchangé.

- `assets/cf-hm.css` : nouvelle feuille de style (chargée par `sections/cf-head.liquid`)
- `snippets/hm-offer.liquid` : bloc d'achat partagé (prix, packs, bouton), utilisé par le héros et la section Achat
- `sections/cf-*.liquid` : sections réécrites (contenu, réglages et branchement conservés)
- `templates/index.json` : nouvel ordre des sections
